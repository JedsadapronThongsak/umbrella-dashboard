1. ตารางเวลา / อุณหภูมิ / Hysteresis

เลือกวันจันทร์–อาทิตย์อิสระ และเวลาแบบนาฬิกา · ค่าช่วงเปิด/ปิดอุณหภูมิควรรอผลจาก Logging ก่อน ไม่ต้องเดาตัวเลข

2. Wind Calibration & Safety (ESP32)

ค่าจาก ESP32/NVS เท่านั้น · Warning/Critical = RAW Encoder RPM (ไม่บวก Offset) · Wind m/s conversion เป็นข้อมูลแสดงผลเท่านั้น · Save แล้วถอน Approval อัตโนมัติ ต้องทดสอบและอนุมัติผ่าน Local AP ก่อน RF จริง

Wind limits: waiting for ESP32 telemetry

กรอก RPM สองค่าคั่นด้วย comma; ไม่มีการเติมค่าทดลองอัตโนมัติ. หากต้อง Clear ให้กรอก CLEAR. Cloud ตั้งค่าได้เมื่อ ESP32 อนุญาต Cloud Settings; ไม่สามารถอนุมัติความปลอดภัยแทนการทดสอบที่หน้างาน.

3. Auto Retry / Reed Confirmation

กำหนดจำนวนครั้งและเวลารอการยืนยันตำแหน่ง ขณะนี้เป็นการจำลอง RF เท่านั้น

4. OLED Display

ตั้งค่าการเปิดจอตลอดเวลา หรือให้จอพักหลังไม่ใช้งาน

5. Google Sheets / Batch Upload

เลือกประเภทข้อมูลและช่วงเวลาที่ส่งขึ้น Google Sheets; Token เดิมจะไม่ถูกแสดงกลับมาที่ Browser

6. Network / AP / HiveMQ (ขั้นสูง)

⚠ การเปลี่ยน SSID, Host, Port, Device ID, Username หรือรหัสผ่านจะมีผลหลัง Restart; หากตั้งผิดอาจต้องกลับไปกู้ผ่าน AP. การแก้สิทธิ์สำคัญต้องใช้ Admin Key

เครื่องมือสำหรับผู้ดูแล

การทดสอบ Sheets และ Reset Fault ไม่เกี่ยวกับการเปลี่ยนโหมด โปรดใช้เมื่อทราบผลกระทบ

การรีสตาร์ตจะตัด Cloud ชั่วคราว และอาจทำให้ Firmware กลับเป็น AUTO ตามการออกแบบ
